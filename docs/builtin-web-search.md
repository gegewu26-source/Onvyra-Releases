# 默认网页搜索

默认入口显示为「自动网页搜索（免 Key）」。仍保留原 `bing_local` 配置类型和现有 ID，已有设置无需重建；其他搜索服务的配置及密钥不会因此修改。

## 查询过程

- 优先获取 Bing 网页结果。结果数量足够且标题、摘要与查询有基本匹配时，只发送这一次查询。
- 结果不足或明显偏题时，尝试搜狗、360 的公开网页结果；仍不足时再尝试 Bing RSS 和 DuckDuckGo Lite。
- 每批最多两个备用来源并行，收到可用结果集后取消剩余请求。单来源约六秒，整次搜索约十四秒上限；取消同时关闭请求及正在读取的响应体。
- 不会调用未选择的付费搜索服务，也不会把其 API 密钥附加到公开搜索请求。

结果解析使用实际页面地址：解开 Bing / DuckDuckGo 跳转链接，读取搜狗和 360 结果中提供的真实目标，拒绝无法还原的搜索跳转、带账号密码的地址和非 HTTP(S) 协议。合并时去掉常见跟踪参数和片段，补充重复结果较完整的摘要，并按关键词匹配排序。显示用的截断网址不会被拼成不存在的页面。

查询中的 `site:example.com` 和 `-site:example.com` 会对所有来源的最终结果统一过滤。域名匹配核对完整主机及其子域，不接受 `example.com.evil`。摘要和检索结果不保证完整或准确，模型仍应读取重要原始来源核实。RSS 的 `pubDate` 只保留来源提供的日期；检索时间不是发布日期。

## 限制与验证

公开搜索页面可能改版、受网络限制或要求验证码。全部来源无结果时明确返回失败，不伪造搜索成功；部分来源返回少量结果时只能交付实际取得的内容。

本轮针对解析、回退、去重、域名限制、超时及取消执行了 16 项 JUnit 测试。另通过桌面 JVM 调用实际搜索实现，验证技术英文、中文天气和限定官方域名三类查询；该实测使用电脑原有代理，不等于已经验证手机的每一种网络。

可选的 `PublicWebLiveProbe` 位于 `search/src/test`，不会打进 APK，也不会调用模型或使用搜索 API 密钥。它需要显式在当前测试运行时中启动，使用结束后关闭测试 HTTP 客户端。
