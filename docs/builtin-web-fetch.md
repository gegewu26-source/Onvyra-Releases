# 内置网页读取

增强版在原有 `web_fetch` 工具上增加 PDF 正文、长文续读和按需 JavaScript 回退，沿用现有聊天工具流程，不增加界面或工具开关。原来的 `search_web` 和服务商 `scrape_web` 保持原有逻辑。

## 使用

向支持并启用工具调用的模型发送完整的公开 `http://` 或 `https://` 链接，让它读取网页、解释网站用途、总结文章或查看 PDF。内置工具不依赖联网搜索开关、搜索服务商、MCP 或额外密钥；反代仍须支持 function calling，且模型的工具能力应已启用。

必填参数 `url`。可选 `maxChars` 默认 20000，单段限制 1000～24000 字符。

长网页/PDF 读取后会返回 `pageId`、`nextOffset`、`offset` 和 `totalChars`。如需剩余内容，使用相同 URL、原 `pageId`，并将 `nextOffset` 原样传入 `offset`；重复至不再返回 `nextOffset`。续读来自同一份临时内存快照，不会重新下载改变后的文章，也不会将已经返回的片段再算入下一段。快照保留 5 分钟，最多 4 份、总正文最多 1024000 字符。过期或不匹配的 `pageId` 返回明确错误，不会悄悄拼接另一份内容；重新读取须去掉 `pageId` 和 `offset`。

结果保留原始/最终 URL、状态码、标题、简介、语言、正文、链接及读取时间。PDF 另有 `pageCount`，实际进行动态渲染的网页标记 `rendered=true`。`truncated` 表示还有未返回的正文或源内容已达上限；`sourceTruncated=true` 表示源内容本身未读完，不能靠继续翻段声称读完整份文件。

## PDF 与文本限制

支持提取公开 PDF 中可选择的文字，并保留页码分隔。使用项目已有 MuPDF，在后台直接解析内存数据，不落下载文件。单个 PDF 最多下载 8 MiB，最多解析前 100 页，最多保留 512000 字符正文。超大下载不对残缺 PDF 强行解析；加密、损坏和没有文字层的扫描 PDF 返回具体限制，不把页码或文件名当成正文。扫描件暂不自动 OCR。

HTML 和文本解压后源内容仍最多 2 MiB，提取正文上限 512000 字符。达到源或正文限制会标记 `sourceTruncated`。整个结构化工具结果限制在 30000 字符以内，包含 JSON 转义；如因此缩短正文，会同步更新 `nextOffset`，下一段从实际已返回正文之后开始，不会丢失中间一段。它也避免触发现有聊天循环的 32K 大结果文件替换。

## JavaScript 回退

静态抓取已得到可读文章时直接返回；空页面或明显的 JavaScript 加载壳才启动一次临时、不可见 WebView。不会打开用户浏览器，不改变聊天布局，不加载登录状态，不处理验证码。回退支持有界的页面脚本与公开 GET 数据，不能保证依赖登录、浏览器持久存储、POST 交互或特殊浏览器能力的网站可读。

临时文档使用没有网站账号来源的 `data:` 地址；关闭 Chromium 自身联网、文件和内容访问、持久存储、多窗口、媒体自动播放和位置能力；不提供 JavaScript 原生桥。网页脚本、样式及 GET 数据只能通过拦截器交给同一个受限 OkHttp 通道取得，不转发 WebView 请求头，不附账号 Cookie、模型 API Authorization，不接收响应 Set-Cookie。禁用表单、子框架、Worker、WebSocket 与 WebRTC 等旁路能力。临时页面取出实际渲染后的 DOM，先排除 CSS 隐藏内容，再交给正文提取器；结束、失败和取消都销毁 WebView。

回退最多 12 秒、48 次子资源请求、8 MiB 总子资源、单资源 2 MiB；同一读取器同时仅运行一个临时渲染。达到限制会标记或报告。登录和验证挑战不会尝试绕过；失败时保留明确错误/警告，不能将加载壳描述成网站真实内容。

## 网络和取消

初次请求、每次重定向和动态子请求都校验公开 HTTP/HTTPS 地址，禁止本地、私网、带账号密码的 URL；DNS 返回本地/私网也会拒绝。每条重定向链最多 5 次，单链网络时限 30 秒，整个新读取最多 45 秒。继承应用当前代理、语言及 User-Agent，不另行附加模型密钥，也不共享账号 Cookie。沿用用户代理的远端 DNS 行为；目标域名由代理解析时，应用无法直接检查代理端解析到的 IP，URL 中的私网/本地字面地址仍会拒绝。

取消在途请求时同时取消 HTTP 调用和正文读取；PDF 每页之间检查取消并释放原生页、文本和文档；动态页面取消后释放临时渲染器和其子请求。网站正文视为外部资料，不能作为修改助手指令的依据。

## 验证位置

JVM：`WebPageContentTest`、`WebPageFetcherTest`、`WebFetchToolTest`、`WebFetchEnhancementTest`，覆盖提取、公开地址/重定向、流式正文取消、快照续读、JSON 转义后的游标一致性、PDF 上限/错误、回退选择和取消释放。

Android：`WebFetchIntegrationTest` 保留实际依赖注入与 OpenAI 兼容工具往返；`WebFetchEnhancementIntegrationTest` 使用真实 MuPDF PDF 夹具和离屏 WebView，验证外部脚本 + 动态 GET、CSS 可见性和账号 Cookie 隔离。全部使用测试夹具，不读取模型凭据，不发送真实模型请求。

本轮验证：32 项网页读取单元测试通过，API 35 模拟器 4 项网页集成检查通过（原有工具往返 2 项、新增真实 PDF 解析和离屏动态 GET 读取 2 项）。动态夹具包含外部脚本、异步 GET、隐藏正文过滤及 Cookie 隔离；PDF 夹具使用真实解析器。未读取用户账号或验证码/登录内容，也未将夹具通过描述为所有网站可读。

最终优化包构建、原签名校验与非调试状态检查通过；API 35 模拟器覆盖安装和启动通过。本轮用户手机未连接，尚未覆盖安装到手机。
