# 本修改版移除原版更新

2026-10-19：按用户要求，此修改版不再检查、显示或下载上游应用的更新。

## 已移除的运行路径

- 移除 `UpdateChecker` 及其依赖注入注册，停用上游更新服务访问。
- 移除 `ChatVM` 的更新状态订阅，以及聊天侧栏的更新卡片。
- 移除更新详情中的 APK 下载链接、`DownloadManager` 更新包下载和该路径产生的下载通知。
- 移除通知设置中的“显示更新”、暂停更新提醒和恢复提醒入口。
- 通知设置入口的说明只保留消息生成通知，避免继续显示“更新提醒”。

检查主源码、Manifest 与 Gradle 依赖后，未发现单独的 Firebase Messaging 更新推送接收器或 Play 应用内更新实现。原版的更新提醒来自以上检查/卡片路径，已经删除。

## 原有设置与通知

保留 `DisplaySetting.updateCheckDisabledUntilEpochMillis` 的字段名、类型和默认值，只用于读取/导出已有设置和备份；没有运行代码再读取它或据此恢复更新。

聊天完成通知、生成过程中的实时通知、保活前台服务通知等仍按用户原有设置工作。“实时更新通知”指生成消息内容的实时通知，与应用版本更新无关。

保留通用的 `Version` 比较工具及其原有单元测试，工具从原来的 `UpdateChecker.kt` 独立为 `Version.kt`，实现不变。关于页面保留离线许可证和必要的来源归属，已移除旧官网与推广入口。

本改动不修改聊天记录、服务商、助手或模式注入等用户数据；也不卸载应用。

## 验证

- 静态检查：主源码中不再存在 `UpdateChecker`、`UpdateCard`、更新接口地址及其调用引用。
- 资源检查：通知设置入口的所有现有语言说明均只描述消息通知。
- 构建时验证 Compose 页面、`ChatVM` 构造函数及 Koin 注册同步更新。
- 可选真机验收：聊天侧栏无版本更新卡片，通知设置无应用更新开关/提醒项；消息通知仍依照原开关工作。

已经由旧版本交给系统下载管理器的下载任务属于系统已有任务，本改动不会删除用户下载或修改系统下载列表。

本轮已核对所有语言 XML 可解析，主 Kotlin 源码没有更新检查器、更新卡片或原更新域名引用；旧暂停字段仅保留数据声明。原有 VersionTest 的 11 项测试通过，调试 APK 与 Android 测试 APK 编译通过。

最终调试/测试/优化 APK 构建通过（2026-10-19）；最终优化包非调试、沿用原包名与签名，API 35 模拟器覆盖安装及启动通过。用户手机未连接，本轮尚未覆盖到手机。
