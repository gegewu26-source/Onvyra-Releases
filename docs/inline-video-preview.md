# 聊天内搜索、解析与播放视频

聊天保持原有布局，在含视频链接的消息或成功的视频解析工具结果下方显示播放器。不会改写发送给模型的原始消息。普通网页和代码示例中的 URL 不自动创建播放器。

## 从片名到播放

内置 `video_search(title, year?, episode?)`：先按片名检索原有三个外部影视目录及已保存兼容目录，核对片名、年份、分集和线路，优先验证 MP4/HLS 等媒体地址。目录阶段失败后，尝试自动发现新的兼容 HTTP JSON 接口，再通过当前所选搜索服务查找、检查和解析网页候选。不需要新增 MCP 或额外 App；网页搜索与模型调用可能按原服务正常计费。本工具独立于原网页搜索开关，模型仍需具备工具调用能力。

自动网页阶段最多两组查询、六个候选、四次页面读取和四次解析，总预算 90 秒。所有有限自动步骤失败后，模型可使用 `video_find_sources` 自主换关键词或原语言片名，再通过 `web_fetch`、`video_resolve` 处理真实页面。明确同名年份歧义时要求补年份，不能猜版本；未知片长不作为已验证整片。接口包出处、发现预算、失败接手和本轮验收见 [movie-source-discovery.md](movie-source-discovery.md)。

`video_resolve(url)` 继续负责已知视频网页或直链。普通网页搜索仍使用原有搜索服务，必要时由 `web_fetch` 检查网页。已知 MP4/HLS/DASH 直链用播放网络栈验证，不为直链启动 Python；视频网页才按需增强解析。

解析成功时工具返回 `video_preview` 元信息，聊天直接展示播放窗口，不依靠模型复制 CDN 播放地址。工具结果只包含原网页、标题、已知时长和本地播放标识；解析出的媒体地址、请求头保存在进程内 64 项、5 分钟的缓存中。缓存过期或 App 重启后可从原网页重新解析。标题和时长供模型区分正片、预告、片段及仅介绍页，不把短片段当成完整电影。

影视目录也返回本地定位信息。缓存过期后重新查询该目录，避免把目录 JSON 当作视频网页交给解析器。不引入新的设置页或影视首页，播放器仍位于原聊天消息的位置。

影片文件不内置在 APK 中。搜索目录来自第三方服务，某部影片能否完整播放取决于真实片源、当前网络、格式及服务可用性；取得目录或 HTTP 200 并不等于完成播放。这里没有原站会员解密或 DRM 破解算法。

## 播放与解析

2026-10-31 播放交互更新：原生视频单击只显隐控件，经过系统双击判定间隔确认；双击切换播放/暂停，每对点击只改变一次播放意图。播放按钮以播放意图而非瞬间是否出画面判断状态，所以缓冲等待中仍可正确暂停；播放结束后第一次点击即可从头重播。

一指横向滑动预览快进/后退的目标时间，松手只跳转一次；被系统取消、双指接管或页面退出时不提交。每滑过一个窗口宽度，时间跨度为片长与120秒中的较小值，并夹取到影片起止位置。滑动不会改变原来的播放/暂停意图。

播放时长按临时使用2倍速，松手、取消、退后台、切换全屏或替换媒体后恢复之前选择的倍速；原档高于2倍时不反向降速。暂停状态长按不会启动声音。全屏原生视频左半边上下滑调当前窗口亮度，右半边上下滑调媒体音量；调节时显示百分比。亮度不写系统设置，退出该全屏窗口恢复此前值；媒体音量按用户调节保留。小窗上下滑继续用于聊天滚动，双指仍用于画面缩放和平移。

全屏按钮不再依赖片源已解析、已加载或没有错误。解析中、错误提示中以及网页播放器都可以先进入应用全屏，媒体随后到达时沿用同一窗口。进入全屏窗口不代表失效线路已经能播放；网页自身的权限和播放控件仍由平台处理。实现参考用户提供的界面和[腾讯播放器 Android 接入说明](https://intl.cloud.tencent.com/ko/document/product/266/33975)，继续使用现有Media3与WebView，不替换SDK或新增设置页。

- 支持识别 B 站 BV/av/番剧影视 ep/ss、b23 短链、抖音、YouTube、TikTok、Vimeo 和常见直链，保留分 P、时间参数。
- 默认使用公开平台播放器或已有 Media3 播放器。MP4、HLS、DASH 可用本地播放器播放；增强解析支持分离的视频、音轨合并播放。
- 聊天内嵌窗口固定为16:9，只有聊天可用宽度变化时才相应改变高度。加载、报错、点击、菜单、字幕、视频元数据和换源都不改变窗口尺寸。默认完整显示原生视频，视频实际显示比例仍考虑非方形像素和旋转。
- 点击画面显示或隐藏控制层，小窗口即可查看当前时间/总时长、拖动进度、播放/暂停、调节倍速及进入全屏。标题和“播放选项”在播放器内上方，其余按钮、时间和进度条在播放器内下方，视频外不再常驻一排操作按钮。
- 控件覆盖在固定画面上，不预留会随显隐改变的上下条带。单击只显示或隐藏控件，不缩放画面、不改变窗口位置。控件隐藏后原视频内容恢复可见；源文件已编码的黑边仍属于视频内容。
- 停止操作约 3.5 秒后隐藏控制层；菜单打开、拖动进度、解析或切换片源期间保持显示，错误时也保留恢复操作。再次点击画面可显示控制层。
- 支持 0.5/0.75/1/1.25/1.5/2/3 倍速。全屏继续使用同一个播放器，保留进度、倍速和播放状态。进入时锁定横屏或竖屏方向，当前全屏会话不随后续源尺寸改变方向；退出恢复此前设置。视频覆盖完整全屏视口，刘海安全间距只用于控件。原生视频默认等比填满，必要时居中裁边，不拉伸；双指收拢可缩回完整画面，张开可继续放大，双指移动可平移且不会拖出空白。结束双指操作不会误触单击；退出回到小窗完整画面，再进入使用默认填满。系统栏可通过边缘滑动临时显示。网页播放器仍受其平台播放器能力影响。
- 不因打开聊天自动播放声音。滑出可见区域或进入后台时暂停，不自动恢复声音。消息销毁后释放播放器及 WebView。
- “增强解析”按需初始化 APK 自带的 yt-dlp/Python；“平台播放器”可返回网页方式。没有额外后台服务、下载器 App 或自动运行时更新。
- 增强解析最长 40 秒，取消或超时会清理进程和临时 Cookie。Cookie 只从当前 App 匹配原网页的 WebView 会话取得，并写入精确域名的临时私有文件，不作为全局请求头发送给其他站点。
- 网页播放器没有原生特权 JS 接口，禁止读取 App 文件、跳转非 HTTP(S) 外部协议、申请摄像头/麦克风等权限。

## 换源与清晰度

倍速、清晰度和换源从各自按钮上方向上弹出细条列表，宽度分别64/88/112dp，小窗与全屏一致。没有可见标题或关闭栏，高度不超按钮上方可用空间并最多224dp，选项上下滚动，当前项用青色标记。点击外侧或返回键收起，不使用固定半屏面板或整屏黑色遮罩，不改变视频窗口尺寸。

优化包针对增强解析运行库补充了反射构造保留规则，避免首次解压时 `ExtraFieldUtils` 初始化失败。可选解析组件出现链接错误时转为可恢复的片源错误，继续保留换源入口。换源查询与来源发现并行、结果增量显示，详细预算与缓存规则见 [movie-source-discovery.md](movie-source-discovery.md)。

电影工具结果的“换源”菜单查询当前目录、其他已配置目录、自动发现并持久保存的兼容接口及同名同年份的各条播放线路；过滤预告、解说、错年和错误分集。配置能下载但没有匹配影片时，不创建该影片的换源项。列表显示来源、片名和线路，目录声称的 4K/高清等版本会明确写成“目录标注”，不等同于实测分辨率。普通视频链接没有影视目录定位信息时不显示换源入口。

选择片源后先解析和验证目标线路，查找期间继续保留当前播放；解析成功才将新媒体载入同一原生播放器，并保留当时的播放进度、倍速、播放/暂停意图和全屏状态。手动解析失败保留旧媒体，并显示可再次选择片源的错误提示。初次解析或原生媒体实际载入/解码失败时，自动尝试其他候选，一轮最多六条、总计 120 秒；单条解析最多 20 秒、原生就绪等待最多 15 秒。正常播放/暂停不自动换源，相同失败项不循环尝试。新片源后续仍可能播放失败，元信息验证不代表全片可用。手动选择后的“重新解析”继续使用所选来源和线路。

播放器自动候选耗尽后，最终由当前会话的 AI 继续自主搜索、检查网页、解析新候选；每个最后用户回合最多自动接手一次，避免无限循环。恢复不能伪造用户消息、覆盖原记录或跳过工具审批，用户取消/停止及会话状态变化时不应抢占续跑。具体实现与运行验证状态见本轮验收记录。

“清晰度”菜单读取当前媒体真实提供且设备可解码的视频轨道，按实际分辨率显示可选档位；“自动”恢复播放器自适应选轨。换源时清除旧媒体的画质覆盖，重新读取新媒体的档位。只提供一种分辨率的 MP4 或 HLS 不会生成虚假的 720p/1080p/4K 选项，可通过换源查找其他版本；播放器无法将模糊源变成高清。网页嵌入方式的清晰度由原平台播放器提供，应用会提示其边界。

依赖版本、校验、许可和原始来源见 [third-party-video.md](third-party-video.md)。解析运行库会增加安装包体积。
