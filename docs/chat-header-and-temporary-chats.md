# 聊天导航与临时聊天

空白聊天右上角显示临时聊天图标，点击进入临时聊天，再次点击退出。临时聊天的空白页可选择「个性化」或「不个性化」，点「完成」才应用选择。

个性化临时聊天可以读取当前助手已经配置的记忆、扩展和指令，但不写入新的记忆。不个性化临时聊天不注入个人记忆、自定义指令或扩展配置。模型及思考参数继续使用用户的选择。

临时聊天在应用的当前会话内存在，不写入本机历史数据库，不参与历史搜索、同步或备份。新建聊天或离开该聊天后取消任务并清理临时会话；这不会撤回已经发送给模型服务商的请求或替用户管理服务商的数据保留策略。

有消息后，右上角变成「新会话」和「更多」：

- 分享：调用已有的会话导出与系统分享功能。
- 置顶／取消置顶：更新当前聊天在历史列表中的顺序。
- 锁定／解除聊天锁定：使用系统锁屏凭据或生物识别验证查看聊天，进入后台或重新打开后重新验证。手机必须先有系统锁屏。此功能是本机查看保护，不是聊天数据库加密。
- 添加到项目：复用当前助手的会话文件夹，可选择或新建项目；不会自动更换模型或助手。
- 已上传文件：列出当前会话各分支中用户上传的本地附件，调用系统应用打开。
- 在聊天中查找：复用原有的当前会话搜索与消息跳转界面。
- 添加到主屏幕：向支持的 Android 桌面请求固定聊天快捷方式；打开锁定聊天仍需验证。
- 归档／取消归档：移出普通聊天列表；可从侧栏「已归档聊天」查看、恢复。
- 删除：先确认，再删除当前会话。

临时聊天只提供分享、已上传文件、查找和删除，不提供产生长期历史条目的操作。

浅色界面的页面背景改为柔和的中性灰白，输入框和菜单为白色，文字和描边使用中性色。深色模式继续可用。聊天输入框原有的模型、思考和手机操控权限按键保留。

构建、测试、设备范围及本次实际验证结果以 `outputs/Onvyra-验收.json` 为准。
