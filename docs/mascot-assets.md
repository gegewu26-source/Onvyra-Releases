# 应用形象

`app/src/main/res/drawable-nodpi/mascot_art.png` 来自用户在本次会话中提供的透明 PNG，1254×1254，原始字节保持不变。

SHA-256：`f3a4401538af4b53eb07621705af4d41af50455613025764093c1c296e35ad75`。

桌面自适应图标、悬浮球、关于页和导出图片使用这张原图。桌面前景保留 18% 安全边距，通知与系统主题图标使用同一角色的单色轮廓。服务商、模型和用户头像保持各自来源。

`mascot_eye_base.png` 由图像编辑工具清除原图的瞳孔得到。动画始终以原图作为完整底层，仅在眼白内部裁剪叠加空白眼底，再绘制活动眼珠；生成底图的其他区域不会显示。

动画实现位于 `MascotIcon.kt`，沿用原加载图标的调用位置和尺寸，以及已有的应用图标加载指示器开关。眼珠以 3.8 秒周期张望、转动，身体轻摇 ±3°。只在页面位于前台时刷新；离开页面、进入后台或关闭系统动画后停止。

动态素材在后台采样解码为约 314×314，共用一组约 0.79 MB 位图缓存。每帧只更新画布绘制，不重组整个聊天列表。

## 回答下方的跑跳动作（2026-10-19）

聊天正在生成回复时，原加载行中的小毛球在固定的 104×44 dp 区域活动，角色仍为 28 dp。4 组动作各持续约 4 秒：摆舞、左右连跳、小跑折返、扭身蹦跳；眼珠继续张望。横移、跳高、旋转与轻微弹性只在画布内绘制，每段返回同一初始姿态，16 秒循环，舞台边界裁剪避免覆盖邻近状态文字。输入栏和消息操作控件保持原布局。

只有聊天回复加载行开启这些动作。侧栏、记忆、压缩上下文等小图标沿用原眼睛动画，静态应用图标不变；关闭原有应用图标加载样式时继续显示标准加载指示器。

沿用同一组共享后台解码位图；没有新增图片序列、计时线程或网络请求。动画限前台约 30 fps，仅使自身画布失效，不在布局或父级组合读取帧状态。回复结束移除该项时取消动画，进入后台或系统关闭动画时停止。
