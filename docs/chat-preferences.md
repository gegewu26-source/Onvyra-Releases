# 聊天翻译与扩展选择

## 消息翻译

消息底部图标位置、尺寸不变。第一次点击仍使用原语言选择对话框；选择后通过 `Settings.messageTranslationLanguage` 保存 BCP 47 标签。之后点击直接使用上次选择的语言翻译，其他消息和重新启动也沿用。长按 1000 毫秒打开原选择器；清除译文不会清除语言偏好。此设置与独立翻译页的 `translateTargetLanguage` 分开保存，互不覆盖。

按钮从现有 `LocalSettings` 读取共享状态，不为每条消息创建磁盘订阅。长按时间只覆盖这个按钮，不改变其他控件。

## 扩展默认

聊天内选择模式注入、Lorebook、Skills 和快捷消息后，所选类别记入当前助手的默认配置，之后的新聊天继承。已有聊天继续使用其持有的配置快照；只修改旧聊天的模型、思考等级或某一类扩展，不会用它其他旧选择覆盖最近的默认。取消全部选择也是有效选择。

界面传递具体类别及基于最新助手的更新函数，避免快速连续选择时回写旧对象。会话配置修改在已有的 metadataMutex 内读取最新状态并串行保存；更新助手默认时从 SettingsStore 最新值合并，避免数据库写入挂起期间覆盖另一项选择。

## 模式停用

管理页停用的模式在聊天及助手扩展列表隐藏，不能从选择列表隐式重新启用。恢复启用须使用原管理页；此前已绑定的 ID 保留，实际发送仍由全局 enabled 状态与当前绑定共同决定。停用的模式不计入聊天附件面板的已选模式数量。

模式注入仍使用原完整输入转换流程，包含上下文裁剪后的动态注入、模板处理和工具续轮。不增加额外提示来强迫模型自报“已经读取”，实际生效依据是发送给接口的内容。

### 系统位置的反代兼容

OpenAI Chat Completions 兼容接口上，启用的模式仍按原位置合并到系统消息，同时在当前用户消息之前补发一条包含这些系统模式要求的临时用户消息。原模式的位置、深度和优先级设置不变，无需改成深度或底部注入；只合并一次，不会随工具轮次累积，也不会拆开工具调用链。

该处理仅针对系统位置的模式注入，不复制助手整体系统提示、Lorebook、网页或工具返回内容。原生 Google/Claude 及 OpenAI Responses 发送路径保持原有行为。不会保存到聊天记录、修改显示内容或额外请求模型，但请求中会多包含一份已启用系统模式的文字，增加相应输入 Token。

位置含义：系统提示之前/之后分别位于同一条系统消息的开头/末尾；对话最开头位于第一条用户消息之前；对话底部位于最后一条消息之前；指定深度从当前发送的消息列表末尾往前计算，1 为最后一条之前。独立消息位置可选用户或助手角色。为避免拆开用户与带工具调用的助手消息，实际插入点可能向前调整；位置和优先级不能保证模型服从。

## 回归范围

测试覆盖翻译首次选择、短按、1000 毫秒长按、更换语言、清除译文、跨消息复用和真实 DataStore 重开；扩展连续点击、并发保存、逐类别默认、新旧会话隔离及落盘重读；停用项隐藏和实际 OpenAI 兼容 /v1 请求中的模式文本。模型请求测试使用固定 HTTP 夹具，不调用用户反代或真实模型账号。

## 真实反代复测（2026-10-19）

反代恢复后，使用用户确认的 `deepseek-v4.1-flash` 验证本次修复。保持系统提示之前/之后，分别测试流式和非流式，每组连续两轮，共 8 次回复均称呼“大哥”；同次只发送原系统指令的对照回复“2”，没有称呼。

首轮使用当前编译产物的真实注入转换器与 OpenAI 请求编码器构造；第二轮带上首轮真实回复，并按相同临时注入结构继续请求。请求与响应的模型字段均为 `deepseek-v4.1-flash`。临时模式内容每次仅一份，原系统内容保留。用户不需要修改模式位置或导入底部注入示例。

这证明所测接口、模型和提示下的真实回复已通过；没有读取反代服务端日志，不能进一步确定之前是代理还是上游忽略了 system。手机当时未连接，接口复测不等于手机覆盖安装或手机界面验收。

## 聊天翻译稳定性修正（2026-10-19）

聊天翻译不再把每个流式片段即时写入整条会话；等待期间保持独立的加载状态，成功后只发布一次完整译文。原有有效译文在重新翻译时保留，失败不再清空整个翻译区。界面显示明确失败原因，空响应不再被保存成“正在翻译”。

译文、加载状态和错误分别表示；加载/错误是临时状态，不作为译文写进聊天数据库或备份。相同消息、原文和目标语言的重复点击合并到同一任务；换语言或清除译文会取消并隔离旧任务，旧回调和旧错误不能覆盖新结果。生成正文的更新需要保留同一消息已有的翻译状态。

译文去掉持续高度动画，加载文字不再透明度闪烁；保留转圈、原译文分区与手动折叠/展开。翻译按钮位置、短按复用上次语言、长按1秒选择语言等行为不变。独立翻译页不改为聊天的最终一次显示方式，仍可使用原流式结果。

生成结束时的最终保存也会合并最新译文状态；完整会话保存与单条译文保存共用会话内持久化锁，避免刚完成的译文被旧快照覆盖，或已清除的译文重新出现。只提取模型实际返回的文本部分，思考部分不参与译文换行；不裁掉文本本身的空格。翻译模型的自定义请求头、请求参数和会话标识继续传递。

## 手机操控权限档位

聊天输入框左下、思考按钮右侧新增小图标，点开后选择「变更前确认」「自主模式」「完全访问」，选择后图标同步变化。
变更前确认会在点击、输入、滑动或打开应用等操作前询问；自主模式只对被判为有风险的操作询问，不能识别目标的坐标点击仍需确认；完全访问不再为手机操控动作逐次弹出确认。
读取界面、等待和停止不因这些档位阻塞。模式按当前聊天保存，明确修改后也成为新聊天默认，打开旧聊天或只改思考级别不会覆盖最近的默认值。
档位由应用传给控制引擎，模型不能在工具参数里自行更改。系统授权、显示屏归属、停止、受保护页面及人工接管仍按原规则执行；它不授予系统 Root 或无障碍权限。
