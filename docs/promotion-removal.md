# 本修改版移除赞助、社区和推广入口

2026-10-19：按用户要求移除主动赞助弹窗、加群与应用推广入口。

## 已移除

- 设置页根据启动次数弹出的赞助提示。
- 设置页“关于”一行的 QQ 群、抖音群、Discord 入口及加群弹层。
- 设置页的赞助入口、捐赠页面、爱发电和 Ko-fi 链接。
- 赞助用户列表、对应网络 API 与依赖注入注册，不再请求赞助名单。
- 设置页向外分享原版 App 宣传文字和官网链接的操作。
- 服务商页的商业推荐按钮、推荐弹层及其静态商家推广列表。
- AiHubMix、APIMart、302.AI、随想 AI 网关、MaruCode 的广告描述、注册返利与推广链接。
- 调试页中已经失去作用的赞助提示计数编辑项。

## 兼容与保留范围

- 所有既有服务商 ID、请求地址、模型配置、开关、余额查询配置和接口类型保持不变。默认商家的推广描述被移除，用户配置的服务仍可正常使用。
- `sponsorAlertDismissedAt`、其偏好存储 key 和序列化映射保留，仅用于已有设置/备份的读写兼容，没有界面再读取它来触发弹窗。
- 保留旧 `Screen.SettingDonate` 序列化 key。若系统恢复了更新前停留在赞助页的导航状态，会显示关于页；不再打开赞助页面或请求赞助 API。
- 保留消息导出、图片分享、服务商配置导入/导出等功能性分享。
- 保留关于页源码/许可证/官网归属信息和使用文档，以及实际功能需要的服务商说明。未改动聊天布局、网页抓取、HTML 预览或吉祥物。
- 已无界面引用的历史翻译资源或图片不再构成运行入口，可随构建资源压缩处理；没有删除用户文件或改写用户数据。

## 静态验证

- 核查主源码中已无 `SettingDonatePage`、`SponsorAPI`、`joinQQGroup`、`RECOMMENDED_PROVIDERS`、推荐弹层等引用。
- 核查主源码中已无 QQ/Discord 邀请、Ko-fi/爱发电链接及 `aff`/`promo` 注册推广 URL。
- 对比默认服务商功能字段，ID、名称、地址、启用状态、接口类型和余额参数保持不变。
- 构建时验证设置页面、旧导航兼容入口与依赖注入注册。

可选界面验收：打开设置页和服务商页，不出现赞助、社区、原版宣传分享或商业推荐入口；消息分享和服务商导入/新增仍可用。

本轮调试 APK 与 Android 测试 APK 编译通过；带当前依赖注入注册的网页工具工厂和聊天往返集成检查通过。原更新路径、赞助接口与社区推广静态引用检查通过，旧设置与旧导航 key 保留兼容。

最终优化包构建、原签名校验与非调试状态检查通过；API 35 模拟器覆盖安装和启动通过。本轮用户手机未连接，尚未覆盖安装到手机。
