设置入口：设置 → MCP → 选择对应服务器 → 工具 → 展开工具 → 设置默认参数。
可保存字符串、数字、布尔参数以及可空的简单参数。默认值只补充本次未填写的参数；AI 明确填写的值优先，包括 0、false 和 null。复杂列表/对象由每次调用填写。更换聊天或重启后偏好保留；刷新工具目录也保留原有工具开关、审批设置和仍符合当前参数规则的默认值。保存只修改本地偏好，不直接运行工具。

Termux 后台故障：这台手机的 Oplus 后台冻结机制会冻结 Termux 并限制其后台连接，导致端口仍监听但连接超时。最终方案通过本机系统后台保护接口，为已核验身份的 Termux MCP 维持一个后台保护令牌；不再直接写进程组冻结文件。守护检查限定 Termux 包、UID、2749端口、运行目录和进程身份；自己的保护进程退出后可恢复。未提供任意命令接口。该保护仅适配当前已验证手机平台，不代表任意 Android 都支持同一个接口。

不需要一直停在 Termux。后台保护依附现有 PhoneTools 守护启动；手动停止 PhoneTools、移除启用标记或关闭对应服务，会结束这项保护。它不会替用户重新打开已明确停止的 Termux MCP。调试和临时验证进程已与正式运行版本区分，交付不包含手机系统框架文件或私有设置。
