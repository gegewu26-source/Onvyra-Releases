All 27 upstream core Kotlin files are retained. No optional plugin runtime,
parser plugin, JS plugin, CLI, native binary, server, or remote-reporting component
is included. The module is compiled against Onvyra's existing OkHttp and
coroutines versions instead of introducing duplicate legacy dependencies.

Onvyra wrapper:
src/main/kotlin/com/constx/onvyra/netdisk/download/TurboNetDiskEngine.kt
Each invocation owns its TurboClient, a stable private output and checkpoint
directory; cancellation pauses, waits for worker cleanup, and retains progress.

Local changes to upstream core:
- MirrorHeaderPolicy.kt additionally strips cloud-provider share-token headers
  on cross-origin mirrors and redirects.
- BuiltinHttpBackend.kt reports a real switch to whole-stream fallback in its
  metadata so the host does not keep labeling it as segmented mode.
- BuiltinHttpBackend.kt strips origin credentials again when adopting a probe's
  cross-origin final URL. The subsequent direct Range requests otherwise reset
  RequestOrigin to that final host and could reattach the original credentials.
